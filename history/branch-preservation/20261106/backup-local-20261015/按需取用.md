## 取回源码

```sh
cd ~/Desktop/URP
git fetch origin
git sparse-checkout disable
git pull --ff-only
```

在另一台电脑使用 `git clone https://github.com/peakpeng666/URP.git`。

## 取回本次实验需要的资料

从云盘或Windows桌面取得 `URP.zip`，在项目根目录执行：

```sh
python3 tools/restore_materials.py /路径/URP.zip --include data/bpp data/packages
```

可指定 `data`、`experiments`、`papers`、`literature/教材`、`src/repos`、`src/backend/backend_data`及其子目录；不指定 `--include` 时取回完整资料。取回工具校验压缩包，并保留GitHub中的源码。

前后端和研究CLI的启动方法见[src](src/README.md)。一次实验结束后，把新配置、代码和报告提交GitHub，原始输出传到云盘并核对，再清理本地运行目录。
