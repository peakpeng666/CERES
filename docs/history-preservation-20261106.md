原有 [2026-10-26 Release 索引](../setup/2026-10-26/local-preservation/recovery-index.json)及其固定哈希完全不改写。新增索引为每个实际下载包记录下载地址、大小与 SHA256；逐条记录给出来源分支、原路径、原 Git blob、包内路径和已核验内容 SHA256，或仓库内惰性资料位置。隐私脱敏项只给公开副本哈希，不发布原文/脱敏双哈希关系。
