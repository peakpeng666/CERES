# 田间作业模型

Lab 把农业任务拆成五个可替换的部分，组合后才有规划问题：

```
环境 × 作物 × 作业 × 车辆 × 机具  →  机组  →  作业行实例  →  方案  →  独立验算  →（可执行时）物理仿真
```

目录在 [`src/lab/urp_lab/agri/data/`](../../src/lab/urp_lab/agri/data/)，全部参数清单见[参数目录](catalog.md)。

## 服务对象：作业行

行作、果园通道与全田覆盖共用一个服务对象：**作业行**，一条机组必须带着工作部件走完的线段。三者只差间距的来源：

| 模式 | 间距 | 例子 |
|---|---|---|
| `swath` 全田 | 机具幅宽 | 耕整、撒肥、无行距作物上的喷杆 |
| `rows` 行作 | 幅宽内可容纳的整数行 × 行距 | 玉米、大豆等行栽作物 |
| `alley` 通道 | 种植行距，一条通道一行 | 果园、葡萄园、茶园、温室 |

障碍把一行切成多段；分段后的各段各是一条作业行，顺序往复按单元推进，不跨障碍交替方向。

按点作业（采样、采收、巡检）和车—车协同（接粮）不属于这个模型，继续走任务地图的 `fleet_routing`。

## 环境决定什么

| 属性 | 进入哪里 |
|---|---|
| `line_operations` | 这里成立的作业。滑移底盘能挂犁，不等于畜禽舍里有耕整作业 |
| `platforms` | 可通行的平台类别，例如水田只允许履带与无人机 |
| `structure` | 作业行模式 |
| `default_crops` | 可选作物，行距来自 `lanes.CROPS`，与 Gazebo 世界同源 |
| `slope_deg` | 只作提示。**坡度没有进入路径成本** |

## 机组怎样由车辆和机具推出

每个派生量都带规则与来源，运行记录保留在 `instance.rig`。

| 量 | 规则 |
|---|---|
| 最小转弯半径 r | 平台半径；牵引机具取其跟随半径 × 1.1 与平台半径的大者 |
| 能否原地转向 | 平台支持且没有牵引机具 |
| 能否倒车 | 平台支持且没有牵引机具 |
| 作业速度 | 机具（或作业）典型速度与平台上限取小 |
| 转弯速度 | 作业速度 × 0.75，不超过转场上限（Hossain & Zahin 2026 算例设定） |
| 转场速度 | 平台行驶速度与 15 km/h 取小 |
| 净空宽度 | 喷杆、撒肥机从作物上方越过，只计车体；其余取车体与机具宽度的大者 |
| 容量 | 机具药箱或料箱；用量 × 幅宽换算为每米需求 |
| 建议地头 | 相邻行转弯所需深度 + 半车长 |

## 适配判断

`assess.py` 比较具体数字并说明改什么。`block` 不生成方案，`warn` 继续但结果受影响，`info` 只说明能力边界。

| 检查 | 依据 |
|---|---|
| 环境 / 作业 / 连接方式 | 目录声明 |
| 载重 | 机具质量与提升或载荷能力 |
| 牵引功率 | ASAE D497：D = F(A + B·S + C·S²)·W·T，P = D·S/3.6；PTO → 牵引按 0.77（D497 图 1 示例，四驱硬地） |
| PTO 功率 | ASAE D497 表 2：a + b·W |
| 通道宽度 | 净通道 ≥ 机组宽 + 0.3 m |
| 轮距与行距 | 轮辙是否压到作物行 |
| 单行需求 | 最长一行不超过容量；行内补给未建模 |
| 地头 | 相邻行转弯所需深度 |
| 轮载 | 单轮 3 Mg 参考值（Horn 2003，转引自 Augustin 2022）；只作提示 |

## 转弯

平行作业行之间，转弯类型由间距 d·w 与半径 r 决定（Bochtis & Vougioukas 2008）：

| 类型 | 条件 | 长度 | 地头深度 |
|---|---|---|---|
| P | d·w ≥ 2r | d·w + (π − 2)r | r |
| U（回绕） | d·w < 2r | r(3π − 4·asin((2r + d·w)/4r)) | r + √(4r² − (d·w/2 + r)²) |
| T（倒车） | 地头放不下 U 且允许倒车 | πr + \|2r − d·w\| | r |
| 原地 | r = 0 | d·w | 车体 |

几何由 Dubins 路径生成，测试把闭式长度与采样几何相互校核。地头内放不下的转弯改走转场：可见图最短路加圆弧过渡，仍放不下时用航向格点 A\*。

## 决策问题

给定作业行集合、容量 Q、续航 E、补给站与 K 台机组，决定**行序、方向、分配和补给点**，使目标最小：

- `nonworking`：非作业里程（转弯、转场、补给往返）；
- `makespan`：最晚完成时间，含转弯、转场和补给服务时间。

所有算法只负责给出行序。补给点由同一个线性时间切分确定（滑动窗口上的最短路，思路同 Prins 2004 与 Hossain & Zahin 2026），所以方法比较只反映排序本身。

| 算法 | 做法 |
|---|---|
| `agri.sequential` | 顺序往复，按单元逐行；驾驶员或 AB 线的做法 |
| `agri.skip` | 每次跳 ⌈2r/w⌉+1 行，全部用 P 型转弯 |
| `agri.split_anneal` | 行序与方向上做模拟退火，分周期降温并从当前最好解重启 |
| `ortools.field` | 每行两个方向建成互斥节点，引导局部搜索；独立实现，用于交叉检查 |
| `agri.exact` | Held–Karp + 趟次精确划分，≤ 12 行，单机组，用于校验启发式 |

实验结论见[研究报告](../../experiments/runs/field-ops-20261107/REPORT.md)：排序的收益集中在 2r/w > 1 的机组，非作业里程少 40% 左右；2r/w ≤ 1 时顺序往复已接近最优。里程收益不等于工期收益。

## 验算

[`check.py`](../../src/lab/urp_lab/agri/check.py) 只读实例和导出几何，不导入求解侧代码。复算：出发与返回、路径连续、分段长度、用时下限、每行恰好作业一次、作业几何与实例一致、容量、续航、最大曲率、车体足迹、倒车权限、覆盖率。

## 指标

| 指标 | 定义 |
|---|---|
| 非作业里程 | 总里程 − 作业行里程 |
| 最晚完成 | 各机组分段用时之和的最大值 |
| 田间效率 | 作业行理论用时 / 全部机组用时。定义同 ASAE EP496，是规划值，不含停机与操作损失 |
| 加注 | 补给站停靠次数 |
| 覆盖率 | 作业带并集 ∩ 内缩作业区 / 内缩作业区；地头不计入 |
| 碾压比 | 左右轮迹（含转弯与转场）的并集面积 / 田块面积，是几何量，不是压实预测 |
| 穿越作物 | 转场穿过作物区的里程。只在障碍把地头隔断时出现 |

## 三层能力

展示、规划、执行是三件事，`tier` 记录每台平台到哪一层：

| 层 | 含义 | 平台 |
|---|---|---|
| 展示 | 只有外观与描述 | 温室轨道车 |
| 可规划 | 有规划参数，可求解、比较、验算 | 其余 |
| 可仿真 | 有执行模型 | 田间差速机器人 |

可仿真时，方案以 `fleet_view` 形式进入 Gazebo 与 MuJoCo：几何不变，并通过原有多车检查器复核。仿真执行的是路径跟踪，机具、药箱与作物不在物理模型里。世界在田块外留 6 m 机耕路用于停车。规划层的工期（含转弯限速与补给时间）与仿真工期（恒定行驶速度下的跟踪）不同，不能直接相减。

## 参数假设

目录里标为「假设」的参数是可调默认值，没有型号依据或厂商未公开。主要几类：

- 类别模板（120 kW 拖拉机、联合收获机、水田履带底盘）的全部尺寸；
- 机具质量、长度、容量的默认值；
- 多数平台的最小转弯半径、车长与轮距；
- 灌装时间（固定 240 s + 200 L/min）；
- 原地转向角速度 0.8 rad/s；
- 平台坡度参考值；
- 未列在 D497 的作业（移栽、修剪、逐株检查等）的速度与效率。

来源分两级：`document` 是读过原文或规格页，`search_summary` 只核对到检索摘要，界面在来源提示里标明。Naïo Oz 尺寸、GUSS 转弯半径等查不到时按假设处理。

## 未建模

- 土壤沉陷、压实力学（Soil2Cover 的 SoilFlex 尚未接入）；
- 坡度对速度、功率与侧翻的影响；
- 行内补给与可拆分边需求（Wan 2023）；
- 多田块转场、多种机组混编；
- 接粮车—收割机协同；
- 喷雾飘移、重喷质量；
- 机具提升与落下的时间损失；
- 加减速。
